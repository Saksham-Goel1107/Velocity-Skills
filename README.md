# Velocity Agent Skills Repository

A comprehensive collection of 11 production-ready **Agent Skills** for Velocity Cloud Sandboxes, designed for AI agents (Cursor, Claude Code, Codex, Custom Agent Frameworks).

## Included Skills

1. **Velocity-cloud-sandboxes**: Workflow decisions, API specifications, discrete hardware allocations, and lifecycle control.
2. **Velocity-sdk-and-cli**: TypeScript SDK (@fairarena/velocity-cloud-sandbox) and CLI (elocitycloudsandbox) syntax and programmatic sandbox control.
3. **Velocity-oauth-and-sso**: OAuth 2.0 Authorization Server, OIDC discovery, token exchange, Clerk integration, and single sign-on (SSO).
4. **Velocity-mcp**: Model Context Protocol schema definitions, tool parameters, error codes, and response shapes for Velocity MCP Server.
5. **Velocity-billing-and-limits**: Single canonical pricing reference, metered per-second billing formulas, and wallet behavior.
6. **Velocity-sharing-and-collaboration**: Link sharing states, SHA-256 password security, and repo share configurations.
7. **Velocity-agent-development**: Complete execution protocol for using Velocity as a remote cloud dev environment.
8. **Velocity-git-and-repositories**: Git version control rules, URL normalization, and agent safety boundaries.
9. **Velocity-resource-selection**: Automated workload-to-hardware allocation guidelines (vCPU, RAM, Disk, GPU).
10. **Velocity-port-and-preview**: Port exposure protocols, IDE/Terminal routing, and application preview link handling.
11. **Velocity-troubleshooting**: Error recovery matrix, failure mode diagnostics, and mitigation procedures.
