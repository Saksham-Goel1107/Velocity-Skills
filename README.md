# Velocity Agent Skills Repository

A comprehensive collection of 9 production-ready **Agent Skills** for Velocity Cloud Sandboxes, designed for AI agents (Cursor, Claude Code, Codex, Custom Agent Frameworks).

## Included Skills

1. **Velocity-cloud-sandboxes**: Workflow decisions, state management, and lifecycle control for Velocity containers.
2. **Velocity-agent-development**: Complete execution protocol for using Velocity as a remote cloud dev environment.
3. **Velocity-git-and-repositories**: Git version control rules, URL normalization, and agent safety boundaries.
4. **Velocity-resource-selection**: Automated workload-to-hardware allocation guidelines (vCPU, RAM, Disk, GPU).
5. **Velocity-port-and-preview**: Port exposure protocols, IDE/Terminal routing, and application preview link handling.
6. **Velocity-billing-and-limits**: Single canonical pricing reference, metered nano-USD billing formulas, and wallet behavior.
7. **Velocity-lifecycle-and-cost-optimization**: Compute cost minimization policies (GPU power hygiene, STOP vs DELETE).
8. **Velocity-sharing-and-collaboration**: Link sharing states, token regeneration, and security boundaries.
9. **Velocity-troubleshooting**: Error recovery matrix, failure mode diagnostics, and mitigation procedures.

## Installation via Agent Skills CLI

```bash
skills add velocity-cloud-sandboxes
skills add velocity-agent-development
skills add velocity-git-and-repositories
skills add velocity-resource-selection
skills add velocity-port-and-preview
skills add velocity-billing-and-limits
skills add velocity-lifecycle-and-cost-optimization
skills add velocity-sharing-and-collaboration
skills add velocity-troubleshooting
```
