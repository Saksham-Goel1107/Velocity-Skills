# Velocity Agent Skills Repository

A comprehensive collection of 12 production-ready **Agent Skills** for Velocity Cloud Sandboxes and Connectors, designed for AI agents (Cursor, Claude Code, OpenAI Custom GPTs, Codex, Custom Agent Frameworks).

## Included Skills

1. **velocity-connectors-and-skills**: 1,000+ Connectors (GitHub, Linear, Slack, Gmail, Google Sheets, Notion, Jira, Supabase) discovery, authentication, schema inspection, and execution.
2. **velocity-cloud-sandboxes**: Workflow decisions, API specifications, discrete hardware allocations, and lifecycle control.
3. **velocity-sdk-and-cli**: TypeScript SDK (@fairarena/velocity-cloud-sandbox) and CLI (velocitycloudsandbox) syntax and programmatic sandbox control.
4. **velocity-oauth-and-sso**: OAuth 2.0 Authorization Server, OIDC discovery, token exchange, Clerk integration, and single sign-on (SSO).
5. **velocity-mcp**: Model Context Protocol schema definitions, tool parameters, error codes, and response shapes for Velocity MCP Server.
6. **velocity-billing-and-limits**: Single canonical pricing reference, metered per-second billing formulas, and wallet behavior.
7. **velocity-sharing-and-collaboration**: Link sharing states, SHA-256 password security, and repo share configurations.
8. **velocity-agent-development**: Complete execution protocol for using Velocity as a remote cloud dev environment.
9. **velocity-git-and-repositories**: Git version control rules, URL normalization, and agent safety boundaries.
10. **velocity-resource-selection**: Automated workload-to-hardware allocation guidelines (vCPU, RAM, Disk, GPU).
11. **velocity-port-and-preview**: Port exposure protocols, IDE/Terminal routing, and application preview link handling.
12. **velocity-troubleshooting**: Error recovery matrix, failure mode diagnostics, and mitigation procedures.
